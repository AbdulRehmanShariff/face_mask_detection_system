Transfer Learning

MobileNetV2 pre-trained on ImageNet (1.2M images) fine-tuned on a custom 7,553-image face mask dataset. Base layers frozen, custom dense head added for binary classification.

👁

DNN Face Detection

Uses OpenCV's deep neural network face detector (SSD + ResNet-10) instead of Haarcascade — significantly better at varying angles, distances, and lighting conditions.

⚡

Real-time Processing

Every webcam frame passes through face detection, cropping, 224x224 normalization, and MobileNetV2 inference in real-time with multi-face support.
